# Sistema de Gestão de Vendas e Estoque - Frontend

Interface moderna e responsiva para gestão comercial, desenvolvida com Angular 21, focada em usabilidade e performance.

## 🚀 Tecnologias
- **Angular 21**: Framework principal com foco em Standalone Components e Signals.
- **Angular Material**: Sistema de design e componentes de interface.
- **Ngx-Charts**: Visualização de dados e dashboards dinâmicos.
- **Signals & RxJS**: Gerenciamento de estado reativo e otimizado.
- **Tailwind CSS**: Estilização utilitária para layouts flexíveis.

## ✨ Principais Funcionalidades
- **Dashboard Estratégico**: Gráficos de faturamento por período e forma de pagamento.
- **PDV (Frente de Caixa)**: Interface rápida para vendas com busca dinâmica de produtos e clientes.
- **Gestão de Estoque**: Cadastro completo de produtos com suporte a imagens e categorias.
- **Gestão de Clientes e Fornecedores**: Cadastros integrados com consulta de CEP e CNPJ.
- **Crediário**: Controle de parcelas, liquidação e histórico financeiro.
- **Relatórios**: Exportação de comprovantes de venda e balanços em PDF.
- **Integração PIX**: Geração de QR Code dinâmico para recebimentos imediatos.

## 🛠️ Desenvolvimento

### Pré-requisitos
- Node.js (v20+)
- Angular CLI

### Servidor de Desenvolvimento
Para iniciar o projeto localmente:
```bash
npm install
npm start
```
Acesse `http://localhost:4200/`.

### Build de Produção
Para gerar a versão otimizada:
```bash
npm run build -- --configuration production
```

## 🧪 Testes
Executar testes unitários com Vitest:
```bash
npm test
```
